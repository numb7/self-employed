# План миграции: Astro + React Islands + shadcn/ui

## Цель
Полная миграция проекта «Финансовый помощник для самозанятых» с vanilla HTML/CSS/JS на Astro + React islands. Реактивные калькуляторы с shadcn/ui компонентами.

## Ключевое правило калькуляторов
- **1 обязательное поле** → результат появляется при вводе
- **2+ обязательных полей** → результат только когда **все** заполнены
- **Опциональные поля** → не блокируют расчёт

### 1.4 Адаптер темы
Утилита `src/lib/theme.ts` — единый модуль для переключения темы (добавляет/убирает `class="dark"` на `<html>`, сохраняет в localStorage). Встроить в Astro через `<script is:inline>` в `<head>` для предотвращения FOUC.

### 1.5 Шрифты
Оставить self-hosted шрифты (Lora, Manrope, JetBrains Mono) — перенести файлы из `/assets/fonts/` в `public/fonts/`. Preload в `<head>` Astro layout.

### 2.2 Принцип Astro pages + React islands

Каждая `.astro` страница — это **статический HTML** с SEO (Open Graph, JSON-LD, meta). Интерактивный калькулятор подключается как React island:

```astro
---
import { SetAsideCalculator } from '../components/react/calculators/SetAsideCalculator';
---

<section id="calculator-set-aside">
  <SetAsideCalculator client:load />
</section>
```

### 2.3 `client:load` vs `client:visible`
- Калькуляторы на странице: `client:load` (первый экран)
- Профиль-виджет в футере: `client:idle` или `client:visible`
- Генератор договоров: `client:visible`

## Фаза 5. Калькулятор-прототип «Отложить на налог»

### 5.1 Реактивная модель (ключевое требование)

```tsx
function SetAsideCalculator() {
  const [payment, setPayment] = useState<number | null>(null);
  const [clientType, setClientType] = useState<'individual' | 'business'>('individual');
  const [deduction, setDeduction] = useState<number | null>(null);

  // Все обязательные поля заполнены?
  const isReady = payment !== null && payment > 0;

  // Результат — только когда isReady
  const result = useMemo(() => {
    if (!isReady) return null;
    return calculateSetAside(payment, clientType, deduction ?? undefined);
  }, [isReady, payment, clientType, deduction]);
  
  // ...
}
```

**Правило для всех калькуляторов:**
| Калькулятор | Обязательные поля | Опциональные |
|---|---|---|
| Отложить на налог | Сумма, тип плательщика | Вычет |
| Лимит дохода | Доход за год, месяц | — |
| ИП или самозанятый | Сумма, тип (НПД/УСН) | Расходы |
| Ставка в час | Сумма, часы | Ставка НПД |
| Взносы на больничный | Сумма страховки | — |
| Пенсионный стаж | — (один из двух: сумма или месяцы) | — |
| Концентрация дохода | Минимум 1 клиент с доходом | — |
| Вычет 10 000 | Сумма оплаты | Остаток вычета |
| Договор/акт | Все поля формы | — |
| Риск переквалификации | — (чекбоксы, любой выбор) | Доля заказчика |
| Часы 289-ФЗ | Часы | — |
| Мастер режима | Все 4 шага | — |

### 5.2 UX-паттерн «пустое обязательное поле»

Когда `!isReady`:
- Результат скрыт
- Непустые обязательные поля — нормальные
- Пустые обязательные поля — **подсветка рамкой** (soft accent border)
- Текст-подсказка: «Заполните [имя поля], чтобы увидеть расчёт»

### 5.3 UX-паттерн «результат появился»

Результат анимированно появляется (fade + slide up). Панель результатов — `Card` с разделами:
1. **Big number**: «1 200 ₽» (monospace, font-size: --fs-figure)
2. **Rate**: «4% от 30 000 ₽ · можно тратить 28 800 ₽»
3. **Why list**: раскрывающийся список «Почему столько»
4. **Risk badge**: зелёный/жёлтый/красный индикатор
5. **Next action**: ссылка на связанный инструмент
6. **Trust strip**: «По ставкам ФНС · Актуально на июль 2026 · Без отправки данных»

## Фаза 6. Миграция всех страниц

Порядок миграции (от простого к сложному):

1. **Статические страницы** (no React): poleznoe, metodika, privacy, disclaimer
2. **Простые калькуляторы** (1-2 поля): chasy-289-fz, deduction, pension, contribution
3. **Средние калькуляторы** (2-3 поля): income-limit, set-aside, hourly-rate
4. **Сложные интерактивы**: concentration (dynamic table), risk-trudovyh (checkboxes), contract-generator (form + preview)
5. **Мастер режима** (wizard, 4 шага)
6. **Сравнение ИП/самозанятый** (table output)
7. **Главная** (hub + profile widget)

Каждая страница: Astro layout → JSON-LD → React island → Related tools → Footer
