Политика конфиденциальности

Как обрабатываются данные при использовании калькуляторов.

Аккаунт не требуется

Для использования всех калькуляторов регистрация и авторизация не нужны. Сайт работает без создания личного кабинета.

Расчёты выполняются в браузере

Все вычисления производятся на стороне браузера с помощью JavaScript. Серверная база данных отсутствует — сайт статический.

localStorage

При использовании калькуляторов некоторые параметры (выбранная страховая сумма, введённый доход, режим расчёта) могут сохраняться в localStorage браузера для удобства повторного использования. Эти данные хранятся только на устройстве пользователя.

Введённые суммы не передаются на сервер

Введённые пользователем суммы, ИНН, ФИО и иные данные не передаются на сервер. Вся обработка происходит локально в браузере. Параметры расчёта могут передаваться в URL-адресе страницы для возможности поделиться ссылкой на расчёт.

Аналитика

На сайте может использоваться Яндекс Метрика для агрегированной статистики посещений. В аналитику передаются только технические события (открытие страницы, нажатие кнопок) — суммы, ИНН, ФИО, реквизиты, текст договора и иные потенциально чувствительные данные не передаются.

Подробнее: Условия использования Яндекс Метрики

Как очистить локальные данные

Чтобы удалить сохранённые в браузере данные:

  1. Откройте настройки браузера → раздел «Конфиденциальность» или «Очистить данные».
  2. Выберите «Файлы cookie и данные сайтов» → «Очистить».
  3. Или очистите localStorage через инструменты разработчика (F12 → Application → Local Storage → Clear).

Также можно использовать режим инкогнито — данные не сохраняются после закрытия вкладки.
