# Финансовый помощник для самозанятых

Независимый статический сайт с калькуляторами для самозанятых (НПД-плательщиков) в РФ.
Расчёты выполняются в браузере, данные не передаются на сервер.

**Production:** https://samozanyatye.vercel.app/

## Запуск актуальной версии

Актуальные исходники — `src/` (Astro + React), ресурсы — `public/`. Корневые HTML, `css/` и `js/` относятся к прежней версии и не используются сборкой Astro.

Требуется Node.js 22.12+ или совместимая поддерживаемая версия.

```sh
npm ci
npm run dev
npm test
npm run check
npm run build
npm run preview
```

Vercel: корневая папка проекта `self-employed-fixed`, если загружена вся папка рабочей области; если репозиторий содержит её содержимое — корень репозитория. Команда сборки `npm run build`, результат `dist`, framework Astro. Эти параметры зафиксированы в `vercel.json`.

Сторонняя аналитика в обновлённой версии отключена; суммы и содержимое форм не отправляются в Метрику. Публичный деплой ещё не подтверждён.

## 📊 Калькуляторы

- **Взносы на больничный** — тариф 3,84%, страховые суммы 35 000 / 50 000 ₽, скидки
- **Лимит дохода** — остаток до 2 400 000 ₽, безопасный темп, прогноз превышения
- **Самозанятый или ИП** — сравнение НПД и УСН 6% без работников
- **Мастер выбора режима** — 4 вопроса для рекомендации режима
- **Пенсионный стаж** — стоимость добровольных взносов ОПС
- **Концентрация дохода** — риск переквалификации при зависимости от одного клиента
- **Отложить на налог** — расчёт с учётом частичного вычета 10 000 ₽
- **Ставка в час** — целевая и фактическая ставка с учётом НПД
- **Договор и акт** — генератор шаблона с экранированием ввода

## ⚙️ Ежегодное обновление нормативных данных

1. Создайте `js/rules-2027.js` по аналогии с `rules-2026.js`
2. Обновите ставки, лимиты, МРОТ-зависимые суммы по официальным источникам (ФНС, СФР)
3. Подключите новый файл на HTML-страницах вместо старого
4. Обновите `updatedAt` в файле конфигурации
5. Обновите даты на странице `metodika.html`
6. Запустите тесты: `npm test`
7. При необходимости поднимите версию в `package.json`

Все нормативные параметры находятся в едином файле — дублирования нет.

## 📄 Лицензия

Проект создан для образовательных целей. Не является официальным сервисом ФНС или СФР.

## Дизайн и проверка

Авторская система описана в `design-system/MASTER.md`. Основные интерактивные элементы — `RangeControl`, `PayerCards` и `AnimatedMoney`. Налог на главной и отдельной странице использует общий компонент и одну функцию расчёта.

`npm test` проверяет расчёты, профиль и содержимое документов; `npm run check` — типы; `npm run build` — все маршруты. `node scripts/brand-assets.mjs` пересоздаёт значки и изображение для ссылок.
