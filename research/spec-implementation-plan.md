# Реализация ТЗ, 18.10.2026

Сохраняем принятую систему: белый #ffffff, чернильный #17254b, синий #3455e9, светлый #f1f4fc, вторичный #66718b, границы #e2e7f1; Golos Text. Новые пояснения — короткие раскрываемые блоки рядом с действием, без дополнительных карточек каталога. Единственный выразительный центр главной — текущая графика денег; новые элементы её не конкурируют.

P0: бонус прямо в текущей оплате; мастер — ограниченная ориентация, без полноценного правового подбора; результаты риска — факты вместо псевдодиагноза; платформа — только сочетание двух условий; правдивые подписи.
P1: исключения после оплаты; подтверждение месяца прогноза; оплачиваемые часы/расходы; раскрытие предустановок договора без изменения юридических условий; действия и границы СФР.

Проверка: контрольные примеры ТЗ, тесты границ мастера/платформы, TypeScript, сборка, desktop в браузере. Правовая экспертиза не подменяется реализацией: консервативный мастер и неизменённый шаблон.
